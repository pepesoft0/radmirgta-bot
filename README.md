## 📖 Описание

**Radmir GTA5 Bot** — программа, которая автоматизирует рутину в Radmir GTA5: вскрывает машины, перезаходит на сервер, качает персонажа и нажимает `E` на работах. Статистику можно смотреть в Telegram или Discord-боте.

### ✨ Возможности

#### 🚗 Авто-вскрытие машины 🔓
- Проходит обе мини-игры: 🔧 **монтировка** и 💻 **код-граббер**
- Работает в режимах 🚐 **бусик** и 🚘 **угонка**

#### 🔄 Авто-релог на сервер
- 📡 Автоматически заходит обратно при дисконнектах и рестартах сервера
- ⌨️ Перезаход по кнопке `F1`
- 🎮 Полный перезаход в игру: сам закрывает и заново запускает игру, 🖱️ заход в игру по кнопке
- ⏰ Можно задать время перезахода
- 📱 Управление через Telegram — удалённо, не находясь за ПК

#### 💪 Авто-качалка
- Автоматическая прокачка персонажа в качалке

#### 🏃 Автобег
- Бег по `Shift + W`
- ⚠️ **Не бегает по траектории** — направлять персонажа нужно мышкой 🖱️

#### 🌸 Авто-нажатие E
- Для работ, например, сбор цветов

#### 🔒 Авто-застёгивание ремня безопасности

#### 📊 Статистика
- Статистика в Telegram / Discord-боте
